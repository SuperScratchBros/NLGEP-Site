# NLGEP

**NLGEP — Next Learning Generation Education Program/Next Level Games Entertainment and Proxies**

NLGEP is a file:url project including Browser, Games, Entertainment, Chatting, AI and more

## Features

- **HTML Browsing** — Access sites through Libcurl JS and Wisp Providers and sandboxed iframe.
- **Entertainment** — Sites that have movies and animes routed through a proxy for you.
-**HTML Games** — Open countless file:Url games

## What our browser can do:

-Run HTML5 Games like Slither.io
-Search stuff up
-Load static sites

## What our browser can't do *that proxies can do*

-Support cloudflare
-Support service workers
-Load sites like now.gg, reddit, etc

## 🌐 Deployment

NLGEP can be hosted on a static web hosting platform that supports HTML files or can be hosted though browser file:URL

Click Code, then download zip, their, open the file ending in .html

OR

Click Code, then download zip, in their, open the file ending in .HTML in text, copy all of it, and paste it into any HTML runners such as Google sites, WIX, etc
